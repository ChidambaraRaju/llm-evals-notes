# LLM Evals Notes

Revision notes on evaluating large language models and LLM applications, written while following the CampusX lecture series on LLM Evaluations (Lectures 1–8).

The notes are a single self-contained HTML page — no build step, no dependencies.

## Chapters

1. Why LLM Evals
2. What Is an Eval — Model vs Application
3. The Evaluation Workflow, End to End
4. Why One Pipeline Is Never Enough
5. How to Score: Eval Methods & LLM-as-a-Judge
6. Offline vs Online Evals
7. Evaluating the Model Itself
8. Benchmarks: How They Work, and When Not to Trust Them

## How to view

Open `index.html` in any browser, or serve the repo with GitHub Pages (a `.nojekyll` file is included so the page is served as-is).

```bash
git clone https://github.com/ChidambaraRaju/llm-evals-notes.git
cd llm-evals-notes
open index.html   # or xdg-open / start, depending on your OS
```
